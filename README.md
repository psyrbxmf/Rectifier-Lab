# Rectifier Lab

An interactive, single-page simulator for learning how AC is converted to DC.

**Circuits:** single-phase half-wave, full-wave centre-tap, full-wave bridge, three-phase half-wave and three-phase bridge.

**Devices:** diodes, thyristors (thyristor-controlled rectifier, TCR), a semi-converter, or any mix. Switch each device between diode and thyristor with the chips under "1 Devices".

**Loads and extras:** R, R + L, current source, battery EMF, free-wheeling diode, and source inductance (commutation overlap).

**Learning tools:** nine guided lessons (dropdown), sixteen ready-made examples (dropdown), a "what is happening now" explanation at the cursor, animated current flow, a strip showing which devices conduct, a harmonic spectrum, metric cards (Vdc, Idc, power, power factor, ripple, THD) and a theory-versus-simulation check.

**Controls:** click or drag on the plots to place the cursor, drag the orange handle to change the firing angle, Space plays or pauses, and the arrow keys step the cursor. Every setting is stored in the page address, so any configuration can be shared as a link.

## Run it

It is a single static file with no build step. Open `index.html` in a browser, or host it with GitHub Pages (Settings, Pages, deploy from the `main` branch, `/ (root)`).
Fonts load from Google Fonts; the page falls back to standard fonts when offline.
