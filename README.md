# Rectifier Lab

An interactive, single-page simulator for learning how AC is converted to DC.

**Circuits:** single-phase half-wave, full-wave centre-tap, full-wave bridge, three-phase half-wave and three-phase bridge.

**Devices:** diodes, thyristors (thyristor-controlled rectifier, TCR), a semi-converter, or any mix. Click a device in the circuit, or double-click it, to swap just that device between diode and thyristor.

**Loads and extras:** R, R + L, current source, battery EMF, free-wheeling diode, source inductance (commutation overlap).

**Features:** animated current flow, waveforms with a movable cursor, device-conduction strip, harmonic spectrum, metric cards, a theory-vs-simulation check, and guided lessons.

## Run it

It is a single static file with no build step. Open `index.html` in a browser, or host it with GitHub Pages.
Settings are stored in the page address, so any configuration can be shared as a link.
